- `index.html` — portfolio homepage
- `student-grade-tracker.html`
- `stock-trading-platform.html`
- `alphabot-chatbot.html`
- `hotel-reservation.html`
- `style.css` — shared responsive styling

## Publish with GitHub Pages
1. Create a **public** repository named `codealpha_tasks` under `nishaediga193-tech`.
2. Upload all six website files to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish.

Expected URL: https://nishaediga193-tech.github.io/codealpha_tasks/

The URL becomes live only after the repository and Pages settings are configured successfully.
