System Architecture & Java OOP Design

Engineered with modular abstraction: separate market feeds, portfolio state, and immutable transaction records.

Market.java

Maintains the registry of equities via LinkedHashMap<String, Stock>. Runs the stochastic volatility simulation tickMarket().

Stock.java

Encapsulates ticker symbol, company name, previous price, and current price, computing point changes and percentage shifts.

Portfolio.java

Manages liquidity balance, tracks share holdings, executes buying power checks, and computes net market value.

Transaction.java

An immutable audit log storing BUY/SELL action enums, share volume, unit price, and timestamp for reporting.

Java 25 LTS 
public class Market {
    private Map<String, Stock> stocks;
    private Random random;

    public void tickMarket() {
        for (Stock stock : stocks.values()) {
            double change = (random.nextDouble() - 0.48) * stock.getPrice() * 0.03;
            double newPrice = Math.max(1.0, stock.getPrice() + change);
            stock.updatePrice(newPrice);
        }
    }
}
