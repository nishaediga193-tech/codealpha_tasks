System Architecture & Java OOP Design

Built following robust Object-Oriented principles, separating data models, business logic, and UI execution.

Student.java

Encapsulates student identity and an internal ArrayList<Double> of marks. Provides getter/setter boundaries and computes student-level metrics.

  • getAverage(): Sum of grades / count
  • getHighest(): Peak recorded score
  • getLowest(): Minimum recorded score

GradeTracker.java

Acts as the controller maintaining the master registry of all students. Implements class-wide statistics, duplicate prevention, and tabular formatting.

  • Case-insensitive student lookup
  • Dynamic ASCII formatted summary table
  • Class-wide highest, lowest & average computation

Main.java

Interactive CLI driver with Scanner input, robust exception handling, and an easy menu-driven interface for seamless command execution.

  • Menu Loop with exit validation
  • Defensive numeric parsing
  • Real-time console updates
Java 25 LTS 
public class Student {
    private String name;
    private List<Double> grades;

    public Student(String name) {
        this.name = name;
        this.grades = new ArrayList<>();
    }

    public void addGrade(double grade) {
        grades.add(grade);
    }

    public double getAverage() {
        if (grades.isEmpty()) return 0.0;
        double sum = 0;
        for (double g : grades) sum += g;
        return sum / grades.size();
    }
}
